# TCS Retail Return Policy

## 30-Day Standard Return Policy
Customers can return any eligible retail item within **30 days** of delivery for a full refund or exchange.

### Key Rules & Requirements:
1. **Condition**: Items must be unused, unwashed, unworn, and in their original packaging with all original tags attached.
2. **Return Shipping**: Pre-paid return shipping labels are generated automatically via the self-service online portal.
3. **Exceptions**:
   - Laptops, electronics, and smart accessories are eligible for replacement or return up to **30 days** even if unboxed, provided all original accessories (chargers, cables) are included.
   - Perishable items, hygiene products, and customized/personalized goods are non-returnable unless defective or damaged upon delivery.
4. **Drop-off Locations**: Return items can be dropped off at any authorized TCS Retail store location or FedEx/BlueDart drop-off points.
